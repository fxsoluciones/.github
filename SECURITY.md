# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales, datos personales, registros ni información de clientes en un issue.

Usa la opción privada de reporte de vulnerabilidades de GitHub cuando esté disponible en la pestaña **Security** del repositorio afectado. Si el hallazgo pertenece a un servicio contratado, utiliza el canal privado acordado para ese servicio.

Incluye solo lo necesario para reproducir el problema de forma segura:

- repositorio o superficie afectada;
- impacto observado;
- pasos mínimos de reproducción;
- versión o fecha aproximada;
- evidencia sanitizada, sin secretos ni datos reales.

Confirmaremos recepción cuando exista un canal operativo y coordinaremos alcance, mitigación y divulgación responsable. No publicamos plazos que todavía no podamos sostener.

## Alcance

El contenido público de esta organización no autoriza pruebas intrusivas, degradación del servicio, acceso a datos de terceros ni ingeniería social. La existencia de una política no constituye una certificación de seguridad.
