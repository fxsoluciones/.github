# Soporte

Los issues públicos no son un canal para incidentes de clientes, credenciales, datos personales, contratos ni solicitudes operativas.

- Clientes: usa el canal privado definido para tu servicio.
- Vulnerabilidades: sigue [`SECURITY.md`](SECURITY.md).
- Recursos públicos: abre un issue solo cuando el repositorio indique expresamente que acepta incidencias públicas.

No incluyas secretos, capturas con datos reales ni información de terceros.
