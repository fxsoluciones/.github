# Contribuciones

FX Soluciones Tech todavía no acepta contribuciones no solicitadas en este repositorio de perfil.

Las mejoras internas se entregan mediante cambios pequeños, revisables y trazables. Si en el futuro abrimos un proyecto a colaboración externa, ese repositorio publicará su alcance, licencia, criterios de aceptación y proceso de revisión propios.

No envíes datos de clientes, credenciales ni material confidencial en propuestas, issues o pull requests.
